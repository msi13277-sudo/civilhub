Privacy Policy

Last updated: 10 July 2026

This site is a static reference site. It is built to work without collecting anything from you, and this policy describes that plainly.

What we collect

  • No personal information — the site has no accounts, no sign-up, no forms and no comment system. We do not ask for, or store, any personal data.
  • No cookies — the site does not set cookies and does not use analytics or tracking scripts.
  • Calculators run locally — values you type into the calculators are processed entirely in your browser and are never sent to a server. Links you copy from a calculator contain only the numbers you entered.

Hosting

The site is hosted on GitHub Pages. Like most web hosts, GitHub may collect standard technical information in its server logs (such as IP addresses) when pages are served. This logging is controlled by GitHub, not by this site — see the GitHub General Privacy Statement for details.

External links

This site links to external websites operated by councils, utilities, government agencies and standards bodies. Once you leave this site, the privacy policy of the site you visit applies. We are not responsible for the content or privacy practices of external sites.

Advertising

The site currently shows no advertising. If advertising is introduced in the future, this policy will be updated beforehand to describe any data collected by the advertising provider, and the "Last updated" date above will change.

Questions

If you have a question about this policy, see the Contact page.
